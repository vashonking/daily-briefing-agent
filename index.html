One-time Google Cloud setup

1
Create a Google Cloud project
Go to console.cloud.google.com → New Project → name it "Daily Briefing Agent".
2
Enable Gmail, Calendar, and Drive APIs
APIs & Services → Library → search and enable each one.
3
Create OAuth credentials — Web application type
Credentials → Create Credentials → OAuth Client ID → Web application. Add redirect URI:
https://developers.google.com/oauthplayground
4
Add test users
Google Auth Platform → Audience → Test users → add all your Gmail addresses.
5
Get a refresh token per account
Go to developers.google.com/oauthplayground → gear icon → Use your own OAuth credentials → enter Client ID and Secret. Paste scopes:
https://www.googleapis.com/auth/gmail.readonly https://www.googleapis.com/auth/calendar.readonly https://www.googleapis.com/auth/drive.readonly
Authorize → select account → Continue → Exchange authorization code for tokens → copy Refresh token. Repeat for each account.
Credentials are saved in localStorage and stay on your device only — never sent anywhere except Google's APIs directly.
Add your accounts on the Accounts tab, then click "Run briefing".
